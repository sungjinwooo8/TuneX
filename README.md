TuneX — 3D Sports Car Customization

TuneX is an interactive web application that allows users to explore and customize a virtual sports car in a 3D environment. The project combines modern web technologies, 3D rendering, animations, and state management to deliver an engaging car customization experience.

🚀 Live Demo

Live Website: https://tune-x-snowy.vercel.app/

GitHub Repository: https://github.com/sungjinwooo8/TuneX

✨ Features

* Interactive 3D Visualization: Explore a sports car in a 3D environment.
* Car Customization: Interact with available customization options to personalize the car.
* Dynamic Animations: Smooth animations and transitions for an engaging user experience.
* State Management: Manage customization settings and application state.
* Responsive UI: A modern interface designed for an interactive browsing experience.
* Web Deployment: Deployed using Vercel for easy access.

Note: Confirm that each feature is implemented in the current version before publishing this README.

🛠️ Tech Stack

* Frontend: React.js, JavaScript, HTML5, CSS3
* 3D Graphics: Three.js, React Three Fiber, Drei
* Animations: GSAP
* State Management: Zustand
* Styling: Tailwind CSS
* Build Tool: Vite
* Deployment: Vercel

⚙️ Installation and Setup

Prerequisites

* Node.js
* npm
* Git

Steps

1. Clone the repository

git clone https://github.com/sungjinwooo8/TuneX.git

2. Navigate to the project directory

cd TuneX

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL displayed in your terminal to access the application.

Build for Production

npm run build

To preview the production build locally:

npm run preview
